# 心血管内科用药常识

## 常用降压药类别

1. **钙通道阻滞剂（CCB）**：如氨氯地平、硝苯地平控释片；常见副作用为踝部水肿、面部潮红、牙龈增生。
2. **血管紧张素转换酶抑制剂（ACEI）**：如依那普利、培哚普利；常见副作用为干咳，出现顽固干咳可咨询医生换用 ARB 类。
3. **血管紧张素Ⅱ受体拮抗剂（ARB）**：如氯沙坦、缬沙坦；耐受性较好。
4. **利尿剂**：如氢氯噻嗪、吲达帕胺；注意监测电解质（低钾）与尿酸。
5. **β 受体阻滞剂**：如美托洛尔、比索洛尔；哮喘患者慎用，不可突然停药。

## 服药注意事项

- 降压药应遵医嘱长期规律服用，血压正常是药物起效的表现，擅自停药易引起血压反弹；
- 建议每天固定时间服药并监测血压，记录"血压日记"；
- 服药期间出现头晕、乏力、干咳、下肢水肿等不适，应及时就诊调整方案，不要自行加减药量；
- 硝酸甘油片用于心绞痛急性发作时舌下含服，含服 3 次仍不缓解须立即拨打急救电话。

## 阿司匹林与他汀

- 阿司匹林肠溶片建议空腹服用，用于冠心病等动脉粥样硬化疾病的二级预防；用药期间注意观察黑便、牙龈出血等出血倾向；
- 他汀类药物（阿托伐他汀、瑞舒伐他汀）一般晚间服用，用于调脂稳斑；若出现不明原因肌肉酸痛、乏力、酱油色尿，需警惕横纹肌溶解，立即就医并查肌酸激酶。

> 用药信息仅供科普参考，具体用药方案请遵医嘱。
