# 科室导诊指南

不知道该挂哪个科？可参考以下常见症状与对应科室的对照关系。

## 按症状选科室

| 症状表现 | 建议科室 |
| --- | --- |
| 胸痛、心悸、胸闷、血压异常 | 心血管内科 |
| 头晕伴血压升高或降低 | 心血管内科 |
| 咳嗽、咳痰、咯血、喘息、气短 | 呼吸内科 |
| 发热伴咽痛、流涕 | 呼吸内科或全科医学 |
| 腹痛、恶心呕吐、腹泻、便血 | 消化内科 |
| 尿频、尿急、尿痛、血尿 | 泌尿外科或肾内科 |
| 关节肿痛、腰腿痛 | 骨科或风湿免疫科 |
| 皮疹、瘙痒、皮肤破溃 | 皮肤科 |
| 头痛、头晕伴肢体麻木无力 | 神经内科 |
| 一侧肢体活动障碍、口角歪斜、言语不清 | 立即急诊（警惕脑卒中） |
| 儿童常见病 | 儿科 |
| 女性月经、妊娠相关问题 | 妇产科 |
| 多系统不适、体检咨询、慢病随访 | 全科医学 |

## 急症识别（立即拨打 120）

- 突发剧烈胸痛，持续不缓解；
- 突发一侧肢体无力、口齿不清、意识障碍；
- 严重呼吸困难、口唇发绀；
- 大出血、严重外伤、抽搐不止；
- 晕厥伴意识丧失超过 1 分钟。

## 就诊小贴士

1. 初诊可先挂全科医学，由全科医生评估后再转专科；
2. 就诊时携带既往病历、检查报告和正在服用的药物清单；
3. 如实告知医生症状起始时间、诱因、加重缓解因素；
4. 慢病患者可预约慢性病管理门诊定期随访。

> 本指南仅供导诊参考，最终分诊以医院预检分诊和医生意见为准。
