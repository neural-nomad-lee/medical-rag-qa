# 科室导诊指南

不知道该挂哪个科？可参考以下常见症状与对应科室的对照关系。

## 按症状选科室

| 症状表现 | 建议科室 |
| --- | --- |
| 胸痛、心悸、胸闷、血压异常 | 心血管内科 |
| 头晕伴血压升高或降低 | 心血管内科 |
| 咳嗽、咳痰、咯血、喘息、气短 | 呼吸内科 |
| 发热伴咽痛、流涕 | 呼吸内科或全科医学 |
| 腹痛、恶心呕吐、腹泻、便血 | 消化内科 |
| 尿频、尿急、尿痛、血尿 | 泌尿外科或肾内科 |
| 关节肿痛、腰腿痛 | 骨科或风湿免疫科 |
| 皮疹、瘙痒、皮肤破溃 | 皮肤科 |
| 头痛、头晕伴肢体麻木无力 | 神经内科 |
| 一侧肢体活动障碍、口角歪斜、言语不清 | 立即急诊（警惕脑卒中） |
| 儿童常见病 | 儿科 |
