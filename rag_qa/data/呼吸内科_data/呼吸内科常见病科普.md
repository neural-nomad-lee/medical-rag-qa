# 呼吸内科常见病科普

## 哮喘

支气管哮喘是由多种细胞参与的慢性气道炎症性疾病，表现为反复发作的喘息、气急、胸闷或咳嗽。

### 常见诱因
- 过敏原接触：尘螨、花粉、宠物皮屑、霉菌；
- 呼吸道感染、冷空气、烟雾、剧烈运动、情绪波动。

### 日常管理
1. 避免接触已知过敏原，保持室内清洁通风；
2. 遵医嘱规律使用吸入性糖皮质激素等控制药物，即使症状消失也不可擅自停药；
3. 随身携带速效支气管扩张剂（如沙丁胺醇气雾剂）；
4. 学会使用峰流速仪自我监测。

### 急性发作处理
- 立即远离诱因，保持坐位，使用速效支气管扩张剂；
- 若用药后症状不缓解、口唇发绀、说话不能成句，立即拨打 120 或就近急诊。

## 慢性阻塞性肺疾病（慢阻肺）

慢阻肺是以持续气流受限为特征的可以预防和治疗的疾病，多与吸烟相关。
