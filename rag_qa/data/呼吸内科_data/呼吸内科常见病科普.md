# 呼吸内科常见病科普

## 哮喘

支气管哮喘是由多种细胞参与的慢性气道炎症性疾病，表现为反复发作的喘息、气急、胸闷或咳嗽。

### 常见诱因
- 过敏原接触：尘螨、花粉、宠物皮屑、霉菌；
- 呼吸道感染、冷空气、烟雾、剧烈运动、情绪波动。

### 日常管理
1. 避免接触已知过敏原，保持室内清洁通风；
2. 遵医嘱规律使用吸入性糖皮质激素等控制药物，即使症状消失也不可擅自停药；
3. 随身携带速效支气管扩张剂（如沙丁胺醇气雾剂）；
4. 学会使用峰流速仪自我监测。

### 急性发作处理
- 立即远离诱因，保持坐位，使用速效支气管扩张剂；
- 若用药后症状不缓解、口唇发绀、说话不能成句，立即拨打 120 或就近急诊。

## 慢性阻塞性肺疾病（慢阻肺）

慢阻肺是以持续气流受限为特征的可以预防和治疗的疾病，多与吸烟相关。

### 主要表现
- 慢性咳嗽、咳痰，活动后气短进行性加重。

### 管理要点
- **戒烟是延缓病情进展最有效的措施**；
- 遵医嘱使用长效支气管扩张剂等吸入药物；
- 接种流感疫苗和肺炎球菌疫苗，减少急性加重；
- 病情稳定者可进行呼吸康复训练（缩唇呼吸、腹式呼吸）。

## 肺炎

肺炎是由细菌、病毒等病原体引起的肺部感染。

### 警示信号
- 发热、咳嗽咳痰、胸痛、气促；
- 老年人可仅表现为精神萎靡、食欲下降、意识改变。

### 就诊建议
- 出现高热不退、呼吸困难、口唇发绀、胸痛明显时应及时就医；
- 医生会根据情况安排血常规、胸部影像学检查，并决定是否需要抗感染治疗。
